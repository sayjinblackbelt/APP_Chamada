# 📋 Aplicación de Gestión de Asistencia

[🇧🇷 Português](README.md) | [🇺🇸 English](README.en.md) | 🇪🇸 Español

> Aplicación en desarrollo para hacer más simple, rápido y organizado el registro de asistencia en talleres, grupos y actividades educativas.

## 📌 Origen del proyecto

La idea surgió de una **demanda institucional real identificada en 2025**, relacionada con la necesidad de mejorar y simplificar el registro de asistencia en actividades educativas.

En **2026**, el proyecto pasó de una necesidad operativa identificada al inicio de la estructuración técnica y del desarrollo del MVP.

El objetivo es transformar una demanda real en una solución digital práctica y progresivamente evolutiva, sin vincular públicamente el proyecto a una institución específica.

## 🎯 Objetivo

Sustituir o simplificar procesos manuales de asistencia, permitiendo registrar la presencia desde un teléfono o tableta con pocos toques.

## 📱 MVP

- selección de actividad, taller o grupo;
- lista de participantes;
- registro de presente o ausente;
- registro automático de fecha y hora;
- correcciones antes de confirmar;
- resumen de asistencia;
- historial básico.

## 🧭 Flujo principal

```text
Seleccionar actividad
        ↓
Seleccionar grupo
        ↓
Cargar participantes
        ↓
Registrar asistencia
        ↓
Revisar información
        ↓
Confirmar
        ↓
Guardar historial
```

## 🧠 Principios

1. **Simplicidad antes que exceso de funcionalidades.**
2. Interfaz adecuada para teléfonos y tabletas.
3. Operación rápida durante actividades presenciales.
4. Arquitectura preparada para conectividad inestable y evolución futura.
5. Privacidad y protección de datos desde el inicio.
6. Separación entre datos demostrativos y datos reales.
7. Documentación como referencia para decisiones técnicas.

## 🔒 Privacidad

Las aplicaciones de asistencia pueden tratar datos personales. Los repositorios públicos no deben contener datos reales de participantes, listas reales, credenciales, tokens ni claves de API.

Los ejemplos públicos deben utilizar datos ficticios o anonimizados.
