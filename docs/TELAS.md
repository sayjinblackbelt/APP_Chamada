# Especificação das telas — MVP

## 01 — Início / Unidade

**Objetivo:** iniciar uma chamada.

Componentes:
- título do aplicativo;
- data atual;
- seleção das duas unidades;
- botão de continuidade.

Critério de aceite: o usuário consegue selecionar uma unidade em um toque.

## 02 — Oficina / Turma

**Objetivo:** escolher a atividade.

Componentes:
- unidade selecionada;
- lista de oficinas/turmas;
- botão voltar.

Critério de aceite: somente oficinas da unidade selecionada são exibidas.

## 03 — Chamada

**Objetivo:** registrar presença.

Cada educando fictício aparece em uma linha/cartão contendo:
- nome;
- estado atual;
- ação Presente;
- ação Ausente.

Também exibir:
- total de educandos;
- presentes;
- ausentes;
- não marcados;
- botão Finalizar.

Critério de aceite: o registro pode ser alterado antes da confirmação.

## 04 — Revisão

**Objetivo:** conferir antes de salvar.

Exibir:
- oficina/turma;
- data;
- presentes;
- ausentes;
- não marcados;
- botão voltar para correção;
- botão Confirmar Chamada.

Critério de aceite: a chamada somente é persistida após confirmação.

## 05 — Histórico

**Objetivo:** consultar chamadas anteriores.

Exibir:
- data;
- oficina/turma;
- quantidade de presentes;
- quantidade de ausentes.

Critério de aceite: chamadas confirmadas aparecem no histórico.

## Regras de UX

- toque confortável;
- tipografia legível;
- alto contraste;
- feedback visual imediato;
- nenhuma ação crítica deve depender de gesto complexo;
- evitar menus escondidos;
- o fluxo normal deve exigir poucos toques.
